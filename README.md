# 批灵 · 快批智能体独立产品线原型

基于 PRD v1.0 的可交互高保真原型（每日工作卡 + 微信/App 双端演示）。

- 单文件自包含 HTML（内联 CSS/JS），浏览器直接打开即可
- 演示控制台可切换：6 场景 × 2 端（微信端老板 / App 端确认台）
- 覆盖：每日工作卡（补货/催收/月报）、问数边界、草稿单闭环、30 天排班

## 本地运行
直接双击 `index.html` 或用任意静态服务器：
```bash
npx serve .
```
